# External Integrations

## Backend Services
- **Firebase:**
  - Authentication (`firebase_auth`)
  - Analytics (`firebase_analytics`)
  - Crash Reporting (`firebase_crashlytics`)
  - Cloud Messaging (`firebase_messaging`)
  - Firestore (Core backend storage)
- **Google Sign-In:** `google_sign_in` for authentication

## Hardware Integrations
- **Camera:** `camera`, `mobile_scanner`
- **NFC:** `nfc_manager`, `nfc_manager_ndef`
- **Storage:** `shared_preferences`, `flutter_secure_storage`, `path_provider`

## Payments
- **Razorpay:** `razorpay_flutter` integration for handling transactions

## System Features
- **Deep Linking:** `app_links` for handling incoming URLs
- **Notifications:** `flutter_local_notifications`, `firebase_messaging`
- **Permissions:** `permission_handler`
- **Contacts:** `flutter_contacts`
- **Web Browser:** `url_launcher`
- **Sharing:** `share_plus`
